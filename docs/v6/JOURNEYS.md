# The v6 Journeys, J01 To J22

The owner's v6 package (`docs/v6/package/07-VERIFICATION-AND-JOURNEYS.md`) names twenty-two whole-system journeys. This is
where each one stands, read against the tests on November 13, 2026. `tests/v6-journeys.test.ts` fails a row whose cited
file is gone, a status that isn't one of the three below, and a row called Covered with no browser journey.

- **Covered**: every step the package lists is run by a test the CI runs, and at least one of them through the screens.
- **Partly Covered**: the core runs, and the row says which steps don't.
- **Not Covered**: no test runs it as a journey; pieces may be tested on their own.

Nothing here is a played-through human check. The package asks for human playtesting of clarity and pacing as well, and
none has been done for these journeys.
