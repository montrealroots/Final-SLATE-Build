## What this is
A build specification and acceptance package for the entire connected film/television career loop. It expands the preceding historical-world command and preserves the source-first creative direction. It is not an imported historical database, an executable installer, or a claim that all requirements already exist. No historical results or private deal terms are fabricated in this package. The implementer must inspect the latest repository and verify external evidence before importing it.

The target experience: choose a source, receive a coherent editable adaptation, assemble people and resources, make the project through its actual production method, choose a release route, see audiences and money arrive, build a differentiated reputation, and receive opportunities that follow from that record. The wider world advances around this career.

## What counts as complete
Every feature has a player action, prerequisites, persistent state, time/cost consequences, failure/recovery paths, downstream consumers and observed tests. Data coverage and software correctness are separate. A filled form is not an accurate adaptation. A successful API call is not a complete catalog. A passing UI test is not a real-phone usability assessment.

This package deliberately makes realism testable rather than promising 100% fidelity to an inaccessible or unknown real world. Unknown facts remain unknown; simulation remains available and clearly distinguished. Neither status permits silently abandoning the requirement.
