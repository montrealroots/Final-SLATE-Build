# Research And Natural Wording

## Evidence policy

This package defines intended gameplay. It is not a newly researched industry rulebook. Reuse current repository source ledgers, then verify facts needed for each feature against accessible primary material. Do not relabel old assumptions as verified because they appear in this package.

Prioritize organizer rulebooks and edition notices for awards/festivals; official production guidance, public guild/industry publications and manufacturer documentation for production processes; official geographic, timezone, weather and calendar sources for world data. Confirm applicable edition, territory and scope. A union rate is not a universal worldwide wage. A climate normal is not a historical daily observation. A release date or future ceremony date may be unknown.

Record: source ID, URL, publisher, title, edition/year, retrieval date, relevant section, supported claim, affected feature IDs, applicability, and status (verified fact, modeled assumption, projected date, unknown). Keep short paraphrases and permitted excerpts; do not copy full copyrighted rulebooks into the repository. Source availability is not guaranteed. Try another official/public source when access fails, without bypassing access controls. If no authoritative evidence is available, isolate a labeled model or record the limitation and continue other work.

Tools must work without requiring an API key from the user. Anonymous documentation access is useful but not guaranteed unlimited. If a tool is unavailable, use an available supported alternative and record the practical limitation. Do not repeatedly reinstall the environment or add paid dependencies.

## Voice principles

Use direct, specific wording that describes the player situation. Explain what is missing and what the player can do. Keep detailed provenance behind the engine. Do not obscure uncertainty, simulated estimates or contractual consequences. Reuse the repository's verified title-case rules. The examples below define tone, not a new competing capitalization system.

| Situation | Example copy |
|---|---|
| Missing finance | You need another $8,000 to reserve these shoot days. Raise more money or revise the schedule. |
| Required crew unavailable | No animator is available for these dates. Move the production window or look for another candidate. |
| Casting conflict | Maya is already booked on June 12. Choose another date or offer the role to someone else. |
| Script change | This revision changes Scenes 4 and 7. Their footage will need review; the other scenes remain usable. |
| Scene dependency | Scene 8 pays off the clue introduced here. Cutting this scene leaves that setup missing. |
| Creative text | These notes stay with your script. SLATE does not judge the writing itself. |
| Document submission | Your treatment is ready to send. This application will include the current version. |
| Event reminder | Your screening begins in 30 minutes. |
| Event actions | View Screening Details; Travel To The Venue; Decline The Invitation — show only actions that are feasible and relevant. |
| Weather disruption | Rain has stopped the exterior shoot. Move to the interior scene or reschedule the remaining work. |
| Unsupported estimate | A required role has no available candidate yet, so this estimate is incomplete. |
| Reopening save | Your story continues on March 8 at 9:30 a.m. |
| Production complete | The final mix is approved. Review the delivery checklist before sending the film. |
| Planned date | This is a planning date. The organizer has not announced the edition's schedule. |

Do not show invented personal living costs when housing does not exist. Do not show technical status dumps as normal game copy. Do not add a tutorial in this package. Useful contextual help and clear validation are allowed.
